# Documents en attente (non affichés sur le site)

Les fichiers de ce dossier ne sont pas publiés : le site ne lit que le dossier `documents/`.
Pour afficher un document aux élèves, il suffit de le déplacer dans le dossier du même nom sous `documents/`
(par exemple `en-attente/seconde/02 - Arithmétique/` → `documents/seconde/02 - Arithmétique/`).

Attention : ce dépôt est public, donc ces fichiers restent consultables sur github.com.
Ne jamais y déposer un sujet de contrôle à l'avance.
